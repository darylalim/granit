# Tests

| Command | Runs | Needs |
|---|---|---|
| `uv run pytest` | `tests/unit/` (the default `-m "not model"`), in seconds | nothing: no weights, no GPU (this is what CI runs) |
| `uv run pytest -m model` | `tests/models/`: smoke and golden tests | downloaded weights (`uv run granit models download`) and the Mac's GPU; nothing else may hold a phase's models (hook H4) |

## Fixtures

- `fixtures/audio/` is generated by `scripts/make_audio_fixtures.py` from macOS `say` (voice *Samantha*) and `afconvert`;
  MP3 / Ogg are encoded with ffmpeg at generation time. Synthetic speech only: no third-party recordings.
  `manifest.json` holds the reference texts and the exact expected speech boundaries.
- `fixtures/documents/` is generated by `scripts/make_document_fixtures.py`: a scanned 2-page report (text, table, bar chart,
  logo), a digital memo PDF (headless Chrome) and an invoice (PNG + PDF) with its JSON Schema. `card_table_truth.json` holds the
  values of the Granite Vision model card's `table.png`, read from the image (the card's images come with the model download).
  `report.document.json` / `memo.document.json` are Docling's output for those PDFs (from `granit convert`), so chunking and search
  are tested in CI without models; regenerate them after changing the document pipeline.

## Third-party test data

- **LibriSpeech** (`hf-internal-testing/librispeech_asr_dummy`, pinned revision; derived from LibriSpeech by
  Panayotov et al., **CC BY 4.0**, <https://www.openslr.org/12>). `tests/models/test_audio.py::test_librispeech_wer`
  downloads its 73 clips (~8 min) at test time to check WER on real read speech. It's never committed, and the test is
  skipped when offline.
